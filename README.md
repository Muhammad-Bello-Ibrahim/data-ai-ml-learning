# Data, AI & ML Learning

A public record of my hands-on learning in Python, data engineering, machine learning, and applied AI. I use this repository to turn lessons into small, reproducible exercises and projects.

## Current starting point

- **Python Data Fundamentals (DataCamp):** beginner section completed; working through the intermediate section.
- **Data Engineer in Python (DataCamp):** enrolled; planned after the Python foundation.
- **Machine Learning Engineer (DataCamp):** enrolled; planned alongside practical ML projects.
- **CS50’s Introduction to Artificial Intelligence with Python:** planned study resource.

These are learning goals, not completed certifications or production models.

## Learning path

| Stage | Focus | Evidence to add here |
| --- | --- | --- |
| 1. Python foundations | Intermediate Python, functions, collections, files, debugging | Short scripts and exercise notes |
| 2. Data work | SQL, pandas, cleaning, exploratory analysis, visualization | Reproducible notebooks and data dictionaries |
| 3. Data engineering | APIs, ETL/ELT, databases, data quality, pipelines | Small pipelines with tests and run instructions |
| 4. Machine learning | Statistics, model evaluation, scikit-learn, leakage, baselines | End-to-end experiments and honest metrics |
| 5. Applied AI | CS50 AI concepts and responsible healthcare use cases | Carefully scoped demos with synthetic or public data |

## Repository layout

- [`learning-log/`](learning-log/) — dated notes, what I built, and what to improve.
- [`python/`](python/) — Python fundamentals and exercises.
- [`data-analysis/`](data-analysis/) — cleaning, SQL, exploration, and visualization.
- [`data-engineering/`](data-engineering/) — ingestion, transformation, and pipeline practice.
- [`machine-learning/`](machine-learning/) — baseline models, evaluation, and experiments.
- [`projects/`](projects/) — complete, documented portfolio projects.

A folder gets real work as I reach that stage. Each project should include its question, data source and license, setup steps, method, results, limitations, and next steps.

## Working rules

1. Write code I can explain, run again, and improve.
2. Keep raw private data, credentials, large datasets, and generated environments out of Git.
3. Use public or synthetic data for healthcare examples; never upload patient records.
4. Document what I learned and what remains incomplete.
5. Prefer a small working project over a collection of copied notebooks.

## Getting started

Clone the repository, create a Python virtual environment, and add dependencies per project when they are needed. The repository does not yet prescribe one environment for every future exercise.

```bash
git clone https://github.com/Muhammad-Bello-Ibrahim/data-ai-ml-learning.git
cd data-ai-ml-learning
python -m venv .venv
```

See [the learning log template](learning-log/README.md) for recording a session.
